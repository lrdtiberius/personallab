PERSONALLAB 2.5.11 AUF ZIMAOS

EnergieLab 0.6.6 liefert PersonalLab auch Wasser und Abwasser. Beide verwenden
denselben Wasserzaehler; Vertrag, Kosten und Zahlungen bleiben getrennt.

1. Paket nach /DATA/AppData/personal-lab-stack entpacken.

2. Vorhandene Installation direkt aktualisieren:
   cd /DATA/AppData/personal-lab-stack
   chmod +x update.sh build-images.sh build-and-export.sh
   ./update.sh

   Das Skript sichert personallab.json, baut beide Images und erstellt die
   beiden Container mit der bestehenden .env und dem bestehenden Datenordner neu.

3. Optional Images als TAR fuer einen anderen Docker-Rechner exportieren:
   ./build-and-export.sh
   docker load -i personallab-2.5.11-images.tar

4. Das bereits laufende EnergieLab 0.6.6 unverändert lassen. Das Build-Skript
   baut und exportiert ausschließlich PersonalLab.

4a. Für die bessere Suche in .env die erreichbare Adresse des bereits
    vorhandenen Containers paperless-rag-webui:3.0.4 eintragen:
    PAPERLESS_RAG_URL=http://ADRESSE-DES-RAG-CONTAINERS
    Die KI-Suche startet erst nach Enter oder einem Klick auf „Suchen“.

5. Konfiguration anlegen:
   cp -n .env.example .env
   nano .env

6. Datenspeicher vorbereiten und starten:
   mkdir -p /DATA/AppData/personal-lab
   chown 10001:10001 /DATA/AppData/personal-lab
   docker compose --env-file .env -f compose.yaml up -d
   docker compose --env-file .env -f compose.yaml ps
